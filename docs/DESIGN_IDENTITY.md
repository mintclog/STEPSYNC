# STEPSYNC 디자인 정체성

> **Current Direction:** Sport Tech × Music Editorial
>
> 러닝 데이터의 명료함과 음악의 리듬감을 하나의 시각 언어로 결합한다.

---

## 1. 문서 목적

이 문서는 STEPSYNC의 현재 디자인 방향을 정리한다.

대화에서 제안된 디자인 방향을 기준으로 하되, **정확한 색상 HEX, 폰트, breakpoint, radius 등의 디자인 토큰은 아직 최종 확정하지 않았다.**

따라서 이 문서는 현재의 **디자인 정체성 기준**이며, 세부 디자인 시스템은 실제 화면 설계 과정에서 확정한다.

## 4. 핵심 디자인 원칙

### 4.1 숫자를 주요 시각 요소로 사용

STEPSYNC에서는 다음과 같은 숫자가 서비스의 핵심 정보다.

```text
5:30 /km
170 BPM
166 spm
```

따라서 페이스, BPM, 케이던스 등의 **큰 숫자 자체를 시각적 중심 요소**로 사용한다.

숫자는 크게, 단위는 작게 표현해 정보 위계를 만든다.

### 4.2 음악은 Waveform보다 Beat로 표현

서비스의 핵심은 음악 재생이나 오디오 편집이 아니라 **리듬과 페이스의 관계**다.

따라서 흔한 오디오 waveform보다는 beat / cadence를 연상시키는 간격과 반복을 그래픽 모티프로 사용한다.

예:

```text
●    ●    ●    ●

│  │  │  │  │  │
```

### 4.3 모든 정보를 카드로 만들지 않음

작은 카드가 반복되는 일반 SaaS 대시보드 스타일을 피한다.

- 큰 정보 섹션
- 명확한 구분선
- 큰 숫자
- 충분한 여백

을 중심으로 화면을 구성하고, 카드는 독립된 정보 묶음이 필요할 때만 사용한다.

### 4.4 음악 추천 영역에서는 앨범 아트 활용 가능

전체 UI는 절제된 색으로 유지하고, 음악 추천 화면에서는 앨범 아트가 자연스럽게 컬러와 음악적 감성을 제공하도록 한다.

앨범 아트 사용 여부와 데이터 소스는 제품 기획 측면에서 아직 최종 확정하지 않았다.

### 4.5 AI 클리셰를 피함

AI 서비스라는 이유로 다음 표현을 중심 스타일로 사용하지 않는다.

- 보라색/파란색 AI 그라데이션
- 과도한 glow
- sparkle 아이콘 남용
- AI 챗봇 캐릭터 중심 UI

OpenAI API는 제품의 기술이며, 시각적 정체성의 주인공은 **러닝과 음악**이다.

## 5. 컬러 방향

대화에서 제안된 기본 방향은:

> **Warm White + Near Black + Electric Lime**

이다.

### 역할

- **Warm White** — 전체 배경
- **Near Black** — 주요 텍스트 및 숫자
- **Electric Lime** — CTA, 선택 상태, 핵심 강조
- **Album Art** — 음악 추천 영역에서 부가적인 컬러

### 상태

이 컬러 조합은 **현재 디자인 방향**으로 사용하되 정확한 HEX 값은 아직 확정하지 않는다.

대화에서 예시로 제시했던 `#F7F7F4`, `#171717`, `#C7F000` 등은 최종 디자인 토큰이 아니라 참고값이다.

### 피해야 할 방향

- 다수의 네온 컬러를 동시에 사용하는 UI
- 화려한 배경 그라데이션
- 앨범 아트와 경쟁하는 강한 배경색
- 모든 상태를 포인트 컬러로 강조하는 방식

---

## 6. 타이포그래피 방향

### 6.1 기본 방향

숫자 가독성이 좋은 현대적인 산세리프 계열을 사용한다.

한글, 영문, 숫자가 함께 등장하므로 세 영역의 조화가 중요하다.

구체적인 폰트는 아직 확정하지 않았다.

### 6.2 정보 위계

#### Hero Number

```text
5:30
/km
```

다음 정보에 사용할 수 있다.

- 현재 페이스
- 목표 페이스
- 추천 BPM

#### Supporting Data

```text
166 spm
154 bpm
```

핵심 결과보다 작게 표현한다.

#### Explanation

AI 분석 및 음악 추천 이유가 필요할 경우 일반 본문 크기로 표시한다.

## 7. 레이아웃 방향

### 7.1 큰 섹션 중심

예시:

```text
YOUR RUN

5:52 /km
166 spm

────────────────────

TARGET

5:30 /km

────────────────────

ANALYSIS

169 — 172 BPM
```

정확한 화면 구성은 추후 UI 설계에서 결정하며, 위 예시는 시각적 방향을 보여주기 위한 것이다.

### 7.2 카드 사용

카드는 다음과 같이 독립성이 높은 요소에 사용할 수 있다.

- 추천곡
- 하나의 러닝 기록
- 기록 입력 방식 선택

모든 텍스트와 데이터를 카드로 감싸지는 않는다.

### 7.3 모서리

전반적으로 지나치게 둥근 SaaS 스타일을 피한다.

대화에서 `8~12px` 정도의 절제된 radius가 예시로 제안되었지만 **정확한 값은 아직 확정하지 않았다.**

## 8. 반응형 디자인 — 확정

STEPSYNC는 **PC와 모바일 모두를 지원하는 반응형 웹사이트**다.

기능은 동일하게 제공하되 화면 크기에 맞게 정보 배치를 달리한다.

### 8.1 모바일

현재 방향:

- 한 열 중심의 세로 흐름
- 큰 숫자와 큰 조작 영역
- 터치하기 쉬운 입력과 버튼
- 스크린샷 업로드 접근성을 높임
- 추천곡은 모바일에서 읽기 좋은 세로 목록 중심

### 8.2 PC

현재 방향:

- 넓은 공간을 활용해 러닝 기록과 목표/분석을 병렬 배치 가능
- 여러 러닝 데이터를 모바일보다 더 밀도 있게 표현 가능
- 추천곡의 추가 정보가 있다면 한 화면에서 더 넓게 표시

### 8.3 반응형 구현 방식

`Mobile-first` 구현은 대화에서 제안된 개발 방식일 뿐 사용자 확정사항은 아니다.

정확한 breakpoint와 레이아웃 grid는 UI 구현 단계에서 결정한다.

## 9. 주요 화면의 시각 방향

아래는 디자인 방향을 설명하기 위한 **화면 아이디어**이며 최종 IA/UI로 확정된 것은 아니다.

### 9.1 러닝 기록 입력

확정된 3가지 입력 방식을 명확하게 구분한다.

```text
러닝 서비스 연동
스크린샷 업로드
직접 입력
```

모바일과 PC 모두에서 세 기능을 사용할 수 있어야 한다.

### 9.2 목표 페이스 입력

목표 페이스는 서비스의 핵심 입력이므로 숫자를 크게 보여주는 방향이 적합하다.

```text
어느 페이스로 달리고 싶나요?

5 : 30
 /km
```

### 9.3 분석 결과

AI를 채팅 UI로 표현하기보다 러닝 데이터와 짧은 분석 문장을 중심으로 보여준다.

이는 현재 디자인 제안이며, 분석 결과에 어떤 지표를 노출할지는 제품 기획에서 추가 결정한다.

### 9.4 음악 추천 결과

음악 재생 UI가 아니라 **추천 정보**가 중심이 되어야 한다.

가능한 요소:

- 곡명
- 아티스트
- BPM
- 앨범 아트
- 추천 이유

이 중 곡명/아티스트 외의 정확한 표시 항목은 아직 확정하지 않았다.

## 10. 모션 방향

모션을 사용한다면 **리듬과 데이터 변화에 의미가 있는 짧은 모션**만 사용한다.

대화에서 제안된 예:

- 분석 중 짧은 beat pulse
- 숫자가 결과값으로 수렴하는 전환
- 결과가 나타날 때의 짧은 transition

피해야 할 방향:

- 계속 움직이는 배경
- 과도한 particle
- 의미 없는 parallax
- 긴 연출 때문에 결과 확인이 늦어지는 UI

모션의 구체적인 적용 여부는 아직 확정하지 않았다.

---

## 11. 아이콘 방향

대화에서 제안한 기준:

- 단순한 line icon
- 일관된 스타일
- 실제 제품 UI에서는 emoji 중심 표현을 피함

로고와 서비스 아이콘의 최종 형태는 아직 정하지 않았다.

---

## 12. 로고 방향 — 미확정

서비스명 **STEPSYNC**만 확정되었고 로고는 아직 제작/확정하지 않았다.

대화에서 제안된 아이디어:

- cadence와 beat의 결합
- 두 리듬이 하나로 정렬되는 형태
- `STEP`과 `SYNC`의 타이포그래피 차이를 활용한 워드마크

피하고 싶은 방향으로 제안된 것:

- 흔한 달리는 사람 실루엣
- 음표 + 운동화의 직접적인 조합
- AI sparkle 중심 로고

이는 로고 제작 시 참고 방향이며 아직 확정안이 아니다.

## 13. 디자인 상태 구분

### 확정

- 브랜드명: **STEPSYNC**
- PC와 모바일을 지원하는 반응형 웹사이트
- 서비스는 음악을 직접 스트리밍하지 않으므로 재생 UI를 핵심 기능처럼 설계하지 않음

### 현재 디자인 기준

- 러닝 + 음악의 정체성이 함께 느껴지는 방향
- **Sport Tech × Music Editorial**
- 밝고 절제된 기본 UI
- Warm White + Near Black + Electric Lime 방향
- 페이스/BPM 등 큰 숫자를 주요 시각 요소로 활용
- waveform보다 beat/cadence 모티프 활용
- 카드 사용 절제
- 모바일은 단순하고 크게, PC는 정보를 더 넓게 활용

### 아직 미확정

- 최종 컬러 HEX
- 최종 폰트
- 태그라인
- 로고
- 정확한 border radius
- breakpoint/grid
- 앨범 아트의 실제 사용 여부와 크기
- 분석 그래프 종류
- 모션 적용 범위
- 추천곡 카드의 정확한 정보 구성

## 14. 디자인 핵심 문장

대화에서 제안한 디자인 개념을 한 문장으로 요약하면:

> **Running science, presented like music.**

이 문구는 디자인 방향을 설명하기 위한 내부 문장으로 사용하며 공식 슬로건으로 확정한 것은 아니다.

STEPSYNC의 화면은 **러닝 데이터를 명료하게 보여주면서 음악의 리듬을 느낄 수 있어야 한다.**
